# CampusCafe — Student Order Portal

A 2-page web app (menu + checkout) built with HTML, CSS and JavaScript. No build step or dependencies.

## Run in VS Code

1. Open VS Code → **File → Open Folder…** → choose the `CampusCafe` folder.
2. Install the **Live Server** extension (Ritwick Dey) if you don't have it.
3. Right-click `index.html` → **Open with Live Server**.

(Double-clicking `index.html` also works, but Live Server is more reliable for `localStorage`.)

## Try it

- Add items, use `+` / `−`, filter by category, search by name.
- Click **Proceed to Checkout** with an empty cart to see the block message.
- On checkout, apply `STUDENT15` (needs subtotal ₹150 or more).
- Enter Full Name + Roll Number and confirm the order.

See `CORRECTION_REPORT.md` for every bug fixed and the reflection answer.
